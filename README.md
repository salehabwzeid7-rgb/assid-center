# مركز أسيد لتحفيظ القرآن الكريم — واجهة المعلّم

تطبيق جوّال (Android / APK) لمعلّمي **مركز أسيد** لتسجيل متابعة الطلاب:
**مقدار الحفظ وما سُمِع**، و**الحضور**، و**التقييم اليومي** — بمزامنة لحظية عبر
Firebase ودعم العمل دون اتصال.

---

## التقنيات

| الطبقة | التقنية |
| --- | --- |
| الواجهة | Angular 22 (Standalone + Signals، بلا Zone.js) |
| اللغة | عربية بالكامل مع تخطيط RTL |
| الخلفية | Firebase — Authentication (Email/Password) + Cloud Firestore |
| التطوير المحلي | Firebase Emulator Suite (مصادقة + Firestore حقيقيان على الجهاز) |
| التغليف كتطبيق Android | Capacitor 8 |

---

## المتطلبات

- Node.js 20+ و npm
- **JDK 21** — لبناء APK وتشغيل المحاكي (Gradle 8.14 لا يدعم JDK 25 المرفق مع Android Studio):
  ```
  winget install EclipseAdoptium.Temurin.21.JDK
  ```
- Android SDK (مع Android Studio) لبناء APK فقط.

`firebase-tools` و `concurrently` مثبّتان محليًا ضمن المشروع (لا حاجة لتثبيت عام).

## التشغيل والتطوير (بلا إعداد سحابي)

```
npm install
npm run dev
```

`npm run dev` يشغّل **بأمر واحد**:
- محاكيات Firebase المحلية (مصادقة `:9099`، Firestore `:8080`، واجهة `:4000`)
- خادم Angular على <http://localhost:4200>

كل شيء حقيقي: أنشئ حسابًا من شاشة **«حساب جديد»**، ثم أنشئ حلقات وطلابًا وسجّل
التسميع والحضور والتقييم. البيانات تُحفَظ في `./.emulator-data` وتُستعاد عند إعادة
التشغيل. لا توجد أي بيانات وهمية.

> **دخول سهل للتجربة:** حقل الدخول يقبل **بريدًا كاملًا أو اسمًا بسيطًا** (مثل
> `ahmad`) — إن لم يحتوِ على `@` يُكمَّل تلقائيًا إلى `ahmad@assid.local`. وكلمة
> المرور تقبل 6 خانات بسيطة (مثل `123456`). شعار المركز في `public/logo.svg`.

> لتشغيل الواجهة فقط بلا محاكي: `npm start` (لن تعمل المصادقة/الحفظ حتى يعمل المحاكي
> أو يُضبط مشروع Firebase حقيقي).

## الربط بمشروع Firebase حقيقي (للإنتاج / APK) — يُضبط **مرّة واحدة**

1. أنشئ مشروعًا في <https://console.firebase.google.com>.
2. فعّل **Authentication → Email/Password**، وأنشئ قاعدة **Cloud Firestore**.
3. من **إعدادات المشروع → تطبيقاتك → تطبيق ويب → «إعداد SDK»**، انسخ القيم إلى
   **ملف واحد فقط**: `src/environments/firebase.config.ts`
   (يستهلكه كلٌّ من `environment.ts` و`environment.prod.ts` — لا تكرار).
4. اضبط اسم المشروع في `.firebaserc` ثم انشر القواعد مرّة واحدة:
   ```
   npx firebase login
   npm run firebase:rules
   ```
5. أودِع التغيير في Git. لن تحتاج إلى إعادة أيّ خطوة مع التحديثات اللاحقة.

- **نموذج البيانات مشترك ومبسَّط**: مجموعات على مستوى الجذر
  (`circles` · `students` · `sessions` · `attendance` · `recitations` · `evaluations`)
  يصل إليها كل معلّم مسجَّل الدخول. لا عزل صارم بمعرّف المستخدم.
- **قواعد الأمان** (`firestore.rules`): قراءة/كتابة لأي مستخدم مسجَّل الدخول
  (`request.auth != null`) — بسيطة ومرنة مع حماية أساسية.
- **الدخول**: بريد كامل أو اسم بسيط (مثل `ahmad` → `ahmad@assid.local`)،
  وكلمة مرور 6 خانات تكفي.
- **دون اتصال**: التخزين المحلي الدائم مفعّل — يعمل التطبيق ويحفظ محليًا ويُزامن
  تلقائيًا عند عودة الشبكة (مع مؤشّر «جارٍ المزامنة» وشريط «وضع دون اتصال»).
- **الجوال**: `experimentalAutoDetectLongPolling` مفعّل لموثوقية Firestore داخل WebView.

للتطوير على السحابة بدل المحاكي: اجعل `useEmulator: false` في
`src/environments/environment.ts`.

## السمات (المظهر)

**٢٠ سمة** قابلة للتبديل من **حساب المعلّم ← المظهر**، أو بزر 🎨 في ترويسة اللوحة
(كلّها عربية RTL، ويُحفَظ الاختيار محليًا). تنقسم إلى قسمين:

### القسم الأول — الثيمات القياسية (١٢)

تغيّر ألوان الواجهة فقط وتدعم الوضعين الفاتح والداكن:

| السمة | الطابع |
| --- | --- |
| **الأساسية** | أخضر قرآني + ذهبي + خلفية هادئة |
| **سمة الشعار** | قوس ذهبي بأشعّة + شريط أخضر + أرضية عاجية |
| **سكينة** | أزرق ليلي هادئ + لمسة فيروزية |
| **مِحراب** | عنّابي تراثي + ذهبي + عاجي |
| **الرَّوضة** | أخضر زيتوني + رملي دافئ |
| **نور** | أحادي احترافي عالي التباين + لمسة ذهبية |
| **أزرق صافٍ** | رمادي فاتح ناعم + أزرق هادئ + لمسات خضراء |
| **لوحة الإدارة** | أبيض مائل + بطاقات رمادية + كحلي ومؤشّرات حالة |
| **فيروز دافئ** | خلفية كريمية + نصّ فحمي عالي التباين + فيروزي |
| **ليل حديث** | فحمي عميق + نيلي هادئ + نصّ أبيض ولمسات نيون |
| **كهرمان** | بيج دافئ + بنّي عميق + كهرماني برتقالي |
| **زُمُرّد** | أبيض ناصع + حدود خفيفة + أخضر غابيّ وشارات زمرّدية |

### القسم الثاني — الثيمات الاحترافية المتقدّمة · Full-Surface (٨)

عند اختيار أيٍّ منها **تتحوّل خلفية التطبيق بالكامل** إلى تدرّج غنيّ متمازج، مع
أسطح بطاقات زجاجية (blur) وإبرازات متناسقة (هويّة بصرية ثابتة بلا وضع داكن منفصل):

| السمة | التدرّج |
| --- | --- |
| **سَبَج أزرق** | أسود مزرقّ عميق + إبراز أزرق |
| **فحميّ ملكيّ** | فحميّ داكن + لمسة بنفسجية ملكيّة |
| **فولاذ فيروزيّ** | رماديّ فولاذيّ + لمحة فيروزية |
| **كحليّ جليديّ** | كحليّ عميق + إبرازات زرقاء جليدية |
| **بُنّ إسبريسو** | بنّيّ قهوة دافئ + لمسة فستقية |
| **زمرّد الغابة** | أخضر غابيّ عميق + توهّج زمرّديّ |
| **تيتانيوم فاتح** | رماديّ فضّيّ فاتح بإحساس معدنيّ ناعم |
| **جمر الغروب** | تدرّج غروب من الأرجوانيّ إلى الجمر البرتقاليّ |

شعار المركز في `public/logo.svg` — يظهر أعلى شاشة الدخول (استبدله بملفك للأصل بدقّته).

## الإشعارات

نظام موحَّد بديلًا عن `alert()` / `confirm()` (`core/notify.service.ts` + `shared/toast-host`):

- **توستات** نجاح/خطأ/معلومة/تحميل في أسفل الشاشة.
- **نوافذ تأكيد** أنيقة (modal) لعمليات الحذف والخروج.
- **شريط حالة**: «وضع دون اتصال» و«جارٍ المزامنة…».

## سير عمل الحلقة والجلسات

الحلقة تُدار عبر **جلسات** (حصص)؛ عند دخول المعلّم إلى حلقته:

1. **بدء/متابعة جلسة اليوم** (أو جلسة بتاريخ آخر) — من صفحة الحلقة.
2. داخل الجلسة، ثلاث خطوات متسلسلة:
   - **١ · الحضور** — تحديد حالة كل طالب من القائمة المُسبقة (حاضر/متأخر/مأذون/غائب) بحفظ فوري.
   - **٢ · التسميع** — تسجيل ما سمّعه كل طالب (من/إلى سورة وآية، الأوجه، التقدير…).
   - **٣ · الملخّص** — يُولَّد آليًا: نسبة الحضور، الغائبون، عدد المسمّعين، متوسط التقدير، توزيع التقديرات، من لم يسمّع، وملاحظة الجلسة.
3. **إحصائيات الحلقة** (`/circle/:id/stats`) — تجميع كل الجلسات: عدد الجلسات، نسبة الحضور العامة، مجموع الأوجه، وتفصيل لكل طالب.

## بناء ملف APK

```
npm run apk:debug      # يبني ويُخرج إلى apk/AssidCenter-Teacher-debug-<التاريخ>.apk
npm run apk:release    # نسخة غير موقّعة للنشر
npm run android:open   # فتح المشروع في Android Studio
```

`scripts/build-apk.mjs` يجد JDK 21 و Android SDK تلقائيًا (أو عبر `JAVA_HOME` /
`ANDROID_SDK_ROOT`). التثبيت على جهاز: `adb install -r <ملف APK>`.

> بناء APK يستخدم `environment.prod.ts` (`useEmulator: false`) → يقرأ إعداد
> `firebase.config.ts` مباشرةً. بعد ملئه مرّة واحدة لن تحتاج لأيّ إعداد لاحق.

## التحديثات والإصدارات (Git / GitHub)

الإعداد يُضبط **مرّة واحدة** (`firebase.config.ts` + `.firebaserc` + نشر القواعد).
بعدها دورة التحديث نظيفة بلا إعادة ضبط:

```
git pull                       # اجلب التحديثات
npm install                    # عند تغيّر التبعيات فقط
# عدّل versionCode/versionName في android/app/build.gradle و version في package.json
npm run apk:release            # يبني ويُخرج APK جاهزًا
git tag v1.1.0 && git push --tags
# ارفع ملف apk/ إلى GitHub Releases
```

- إعداد Firebase لا يُلمَس مع التحديثات (ملف واحد مُودَع).
- القواعد تُنشر مرّة: `npm run firebase:rules` (وتُعاد فقط عند تعديل `firestore.rules`).
- `android/` مُودَع في Git → البناء متكرّر بلا `cap add`.

## التنظيف وأدوات الذكاء الاصطناعي

```
npm run clean     # يحذف .angular و dist و android/app/build (تُعاد إنشاؤها آليًا)
```

- **`.aiexclude` / `.cursorignore`**: يستبعدان `android/` و`docs/screens/` والمخرجات
  و`package-lock.json` من فهرسة أدوات الذكاء الاصطناعي — لتقليل استهلاك الـ tokens
  وحصر السياق في `src/`. (`android/` يبقى متتبَّعًا في git لبناء APK.)
- **`.gitattributes`**: يَسِم `android/**` و`package-lock.json` كـ`linguist-generated`
  حتى تُطوى في فروقات GitHub.

## الميزات

- **حساب المعلّم**: إنشاء حساب من الصفر، تسجيل دخول ببريد أو اسم بسيط، إعادة تعيين كلمة المرور، تعديل الاسم/الجوال.
- **الحلقات والطلاب**: إنشاء/تعديل/حذف حلقة، وإدارة قائمة الطلاب المُسبقة بأرقام أولياء الأمور.
- **الجلسات**: بدء/متابعة جلسة اليوم أو أي تاريخ، وإنهاؤها وإعادة فتحها.
- **الحضور**: تحديد حالة كل طالب داخل الجلسة بحفظ فوري + «تعيين الكل حاضر».
- **التسميع**: من/إلى سورة وآية، عدد الأوجه، التقدير، أخطاء الحفظ والتجويد، مرات التلقين، ملاحظات — سجل واحد لكل طالب في الجلسة قابل للتعديل.
- **ملخّص الجلسة الآلي**: نسبة الحضور، الغائبون، عدد المسمّعين، متوسط التقدير، توزيع التقديرات، من لم يسمّع.
- **إحصائيات الحلقة**: تجميع كل الجلسات + تفصيل لكل طالب (حضور٪، جلسات تسميع، أوجه).
- **ملف الطالب**: إحصائيات مجمّعة وسجل كامل، وتقييم يومي (خمسة محاور).
- **مزامنة لحظية** و**عمل دون اتصال** مع مزامنة تلقائية عند عودة الشبكة.
- **سمتان للواجهة** قابلتان للتبديل الفوري (فاتح/داكن لكلٍّ).
